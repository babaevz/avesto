Автозагрузка из папки

Работает только в Chrome / Edge на компьютере. Сайт держит в этой папке файл «реестр_сотрудников_база.xlsx» — свою резервную копию реестра, которая обновляется при каждом изменении и подхватывается заново при следующем запуске.

Папка не подключена.

Эта функция браузера (File System Access API) не поддерживается в текущем браузере — работает в Chrome и Edge на компьютере, но не в Safari, Firefox или на телефоне.
